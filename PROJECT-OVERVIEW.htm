What it does

Features & API route groups

Ten routers mount under /api/*. Reads need a valid session; every mutation is gated by role server-side.

/auth Identity

Sign-in, sessions & account security.

  • Login with per-IP+email rate limiting
  • TOTP set-up / enable / verify / disable
  • Forgot & reset password (hashed, single-use)
  • Change password · self-service deletion

/signup · /staff People

Two ways an account is created.

  • In-app sign-up → admin approval queue
  • Admin adds staff → email invite link
  • Reduced public shape for non-admins
  • Admin 2FA reset · resend invite

/checkins · /leave Attendance

Daily attendance & time off.

  • Check-in / check-out · daily summary
  • Leave requests (staff)
  • Approve / decline (admin)
  • Balance updates flow back to staff

/adjustments · /documents

Allowances & shared files.

  • Manual allowance adjustments (days)
  • Org-wide or personal documents
  • Admin upload / delete
  • Derived balances on the client

/notifications · /devices

The bell & push.

  • DB-backed per-user notifications
  • Mark read · clear
  • Register / unregister FCM tokens
  • Admins told of requests; staff of decisions

/hnd Registers

HND student attendance registers.

  • Semesters · modules · students · enrolments
  • Timetabled sessions, mark P / L / E / A
  • Percentages per module & overall
  • CSV export throughout

The database

Prisma data models

Thirteen models in schema.prisma. Green notes key relations; HND registers cascade-delete from their parents.

Staff
Login identity · accountRole ADMIN/STAFF, allowance, TOTP fields, tokenVersion. has many CheckIn, Leave, Adjustment, Notification.
SignupRequest
Pending applicant, separate from Staff until an admin approves.
PasswordReset
Hashed single-use token · purpose reset (30m) or invite (7d).
DeviceToken
FCM push token per device · belongs to Staff.
CheckIn
Daily attendance · unique(staffId, date).
Leave
Request · type / status / day count.
Adjustment
Manual allowance change, in days.
Document
Org-wide or personal file · optional assignedTo.
Notification
Persisted per-user, survives reload.
Semester
Non-overlapping date range · scopes HND %.
HndModule · Student
joined by Enrolment (unique pair).
HndSession
Timetabled class · dated into a semester.
AttendanceMark
P / L / E / A per session+student · unique pair.

Built-in from the start

Security model

Enforced server-side — the client can't grant itself anything the API won't.

2FA

TOTP two-factor

RFC 6238 on Node crypto — works offline, no third-party cost.

#

bcrypt hashing

Cost 10 · password hashes never leave the API.

JWT

Revocable sessions

tokenVersion bumps on reset — old tokens die instantly.

RL

Rate limiting

Login & reset locked after repeated attempts (HTTP 429).

✓

Admin-approved sign-up

No account exists until an admin approves the request.

↺

Hashed reset links

Single-use, 30-min, revokes sessions on every device.
